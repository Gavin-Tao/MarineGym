## 指标口径

* **`episode_len` 是主指标** —— episode 因跟踪误差 > `reset_thres`(0.5 m) 提前终止，
  故"撑多久"即"跟踪质量"。
* ⚠ **`tracking_err_mean` 无区分度** —— 误差从 0 线性长到阈值就终止，
  均值必然 ≈0.19，与控制质量无关（三个速度档下分别 0.1929/0.1939/0.1943，
  而 episode_len 相差 3.7 倍）。列在这里只为完整性。
* `return` 逐步累加，已把 episode 长度计入；**不可按长度归一化**。

## 任务/条件说明

| 标识 | 含义 |
|---|---|
| `drift` | 原始参考速度 + 未观测执行器增益漂移 U(0.5,1.0) |
| `drift_oracle` | 同上，但把增益告诉策略（oracle 对照） |
| `delay10` | 原始速度 + 观测延迟 160 ms |
| `noff` | 原始速度 + 切断前馈（去未来参考点与时间编码） |
| `slow` / `slow2` | 参考角速度降到 [0.3,0.5] / [0.2,0.35] |
| `s2` | = slow2，无 POMDP（可跟踪任务的基准） |
| `s2_novel` | slow2 + 无 DVL、无速率陀螺 |
| `s2_sparse` | slow2 + USBL 定位 6.25 Hz |
| `s2_sp60_v` | slow2 + USBL 1 Hz + 无 DVL（**唯一有效的 POMDP 条件**） |
| `s2_sp125_v` | slow2 + USBL 0.5 Hz + 无 DVL |
| `s2_noff` / `s2_noff_v` | slow2 + 切断前馈（+ 无 DVL） |
| `s2_wave5` | slow2 + 未观测周期扰动 A=0.5 |
| `key/` | `s2_sp60_v` 条件下的序列模型对比 |
